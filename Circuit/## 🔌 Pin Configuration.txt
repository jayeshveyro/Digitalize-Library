## 🔌 Pin Configuration

### RC522 RFID

| RC522    | ESP32         |
| -------- | ------------- |
| VCC      | 3.3V          |
| GND      | GND           |
| SDA / SS | GPIO 5        |
| SCK      | GPIO 18       |
| MOSI     | GPIO 23       |
| MISO     | GPIO 19       |
| RST      | GPIO 22       |
| IRQ      | Not connected |

### ILI9341 TFT

| TFT        | ESP32   |
| ---------- | ------- |
| VCC        | 3.3V    |
| GND        | GND     |
| CS         | GPIO 17 |
| RST        | GPIO 21 |
| DC / RS    | GPIO 16 |
| MOSI / SDI | GPIO 23 |
| MISO / SDO | GPIO 19 |
| SCK / CLK  | GPIO 18 |
| LED / BL   | 3.3V    |

### Controls

| Component     | ESP32   |
| ------------- | ------- |
| Issue Button  | GPIO 26 |
| Return Button | GPIO 27 |
| Buzzer +      | GPIO 25 |
| Buzzer −      | GND     |
